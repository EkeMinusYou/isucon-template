# ISUCON共通の実装パターン

複数のISUCONに応用できる、性能改善や構成変更の実装パターンを管理する。
特定の大会、アプリケーション、スキーマ、サーバー配置に依存する内容を含めてもよいが、
その依存条件を本文に明記する。

ここにある内容は、そのまま適用する手順ではなく、対象のコード・設定・公式仕様に照らして
適用方法を考えるための参考資料である。特定のリポジトリのファイルやコマンドを例にする場合は、
リポジトリ固有の例であることを明記する。

## 記載ルール

各ドキュメントには、次の項目を含める。

### 概要

何を改善するパターンか、どのような問題に有効かを説明する。

### 適用条件・制約

必要な構成や前提、適用できないケース、維持すべき仕様や制約を説明する。

### 探索方法

対象のコード・設定のどこを、どのような観点や検索語で確認するかを説明する。
適用候補を見つけるための着眼点を記載する。

### 実装方法

一般的な変更方針、代表的なコード・設定例、実装時に確認すべき箇所を説明する。

計測手順、計測結果、ベンチマークの判定基準、ロールバック手順、作業履歴は、
このディレクトリの記載対象外とする。
