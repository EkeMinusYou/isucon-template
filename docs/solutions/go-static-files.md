# 静的データをGoから直接配信する

公開範囲・更新・削除・初期化後の可視性を確認し、不変の公開資材を汎用HTTP土台の`static_routes`へ登録します。[Go HTTPの秘伝のタレ](../special-sources/go-http.md)を参照してください。

`task gen`は`public/`から`generated/public/`へ元ファイルと有効なgzip版を生成します。`task deploy`は設定・資材をGoホストへ配布して再起動します。Goは起動時に登録された資材を読み込み、gzip版の内容一致を検証します。元ファイルと圧縮版のメモリ量を含めて配置を判断してください。

認可付きデータ、更新されるファイル、実行中のアップロードはこの不変資材の領域から分離します。専用Go handlerで認可・更新順序・キャッシュ失効・永続化・複数ホストの整合性を実装します。ファイル配布時に削除される領域へ永続データを置きません。
