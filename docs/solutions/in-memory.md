# Goのメモリ上で状態を扱う

頻繁に参照する状態・索引・集計値をGoのデータ構造で保持します。業務上の正本と派生データを決め、同じ状態を扱う全操作へ一貫して接続します。

データ量・増加量・索引・複製・一時領域を含めてメモリを見積もります。キーで所有権を分ける、immutable snapshotを公開する、更新を直列化する等を比較し、lock待ちとGCを測ります。全ホストへの複製や分散を初めから必須にしません。

初期状態はsetupが分離したファイルから構築します。受理済み更新の通常再起動後の復元は、選んだ永続化方式で実装し、初期化では古い状態・索引・永続化世代を一体で切り替えます。読み取りだけ速くして更新の可視性や重複処理を崩さないでください。
