# WALの分析と保存

WALを採用し、計測の取得元として利用する場合だけ読む。観測項目・標準の集計結果・保存と検証の共通方針は[状態・操作の計測](state-and-operations.md)に従う。

- WALに含まれる操作と含まれない操作を確認する。更新履歴だけから、読み取り・失敗・未開始を含む全操作の進行を説明できるとみなさない。
- 非同期書込みでは受理済み・追記済みを区別する。集計した世代・sequence・時刻の範囲を確定し、追記待ちや回収不足を業務上の結果と混同しない。
- 標準の集計結果は、対象ホストで必要範囲を順に読むなど、WAL全体をローカルへ転送せずに生成できる方法を選ぶ。実際の処理時間・メモリ・I/Oを確認し、毎RUNの全件走査を無条件の手順にしない。
- 詳細分析でWAL原文を回収する場合は、対象RUN・世代・sequenceの範囲を記録する。現在のWALで失われた過去RUNを代用せず、原文を回収しない通常RUNを取得失敗とも扱わない。
- 計測用の保存量を減らすために、復元に必要なWALを削除したり永続性要件を変えたりしない。
