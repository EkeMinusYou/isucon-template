# ISUCON solution の適用可能性を評価する

担当範囲は指定文書の適用条件を現行環境と照合し、適用可能性・変更案・未確定点を報告する。コードや設定の編集・deploy・benchは行わない。

## 対象を選ぶ

`docs/solutions/` 内の指定された一つの文書を、パス、ファイル名、カタログのリンク、一意な名称から解決する。README は対象解決に使い、適用対象にはしない。

指定なし、曖昧、存在しない、ディレクトリ外の場合は対象を確認し、確定までは適用調査を進めない。全件探索へ勝手に広げず、指定外の solution を候補選定に使わない。

## 適用条件と実装経路を評価する

[既知資料の候補評価手順](../_shared/known-solutions.md) に従い、指定文書の範囲内で適用可否を評価する。

対象文書の全文を読み、特に適用条件・制約と探索方法を確認する。資料の手法がシナリオのどの操作や待ち時間に影響し、得点をどう変えると考えられるかを検討する。その見込みを踏まえ、現行コード・SQL・スキーマ・役割配置を調べて適用箇所を探す。

読み書きの所有者、更新・削除・失効、状態の公開順序、障害・初期化・再起動時の経路を必要な範囲で追い、鮮度・整合性・認証認可を維持できるか確認する。変更する箇所と実装方法、正当性への影響、評価方法を示す。

文書内の実装例や共有基盤を必須条件とせず、現在の構成で成立する実装経路を評価する。複数ファイル・ホスト・schema・初期化にまたがる変更も、依存関係と反映方法を含めて報告する。実装・元文書の編集は行わない。

## 完了報告

対象文書と適用可否を先に示し、出典リンク、現行との差分、変更案を報告する。変更によってシナリオの進み方や得点がどう変わると考えているかを説明し、正当性・運用上の条件と未確認点を添える。
