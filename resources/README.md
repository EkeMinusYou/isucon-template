# ISUCON 問題・解説リソース

調査日: 2026-08-23

このディレクトリは、公開されている ISUCON の問題、公式解説、参加者の参加記を、問題と解決策の対応が追える形に整理したものです。

## 収録範囲

「Web 上の全て」を文字どおり完全に列挙することは、削除・移転・検索未収載の記事があるため保証できません。そこで、次の範囲を網羅的な入口として採用しています。

- ISUCON 公式サイトの各回まとめ（ISUCON1〜14）
- 各回の公式問題リポジトリ、当日マニュアル、公式の問題解説・講評
- 公式サイトが収集した参加者の関連エントリまとめ
- 初期回の公式再現記事と、代表的な優勝・上位チームの参加記
- 過去問学習、計測、Web パフォーマンスチューニングの横断資料

個別記事を転載せず、問題の要点と解決策を要約し、原典へのリンクを残しています。公式の想定解、参加者の実戦解、資料からの整理・推論は区別しています。

公式の年次まとめは [ISUCON 公式のまとめ一覧](https://isucon.net/archives/cat_1240788.html) です。完了済みの公開問題として ISUCON1〜14 を扱い、ISUCON15 は公式の歴代一覧で確認できなかったため収録対象外としました。ISUCON2026 は 2026-10-31 開催予定で、調査日時点では問題・解説がまだ公開されていません（[開催告知](https://isucon.net/archives/59917350.html)）。

## ファイル

- [official-resources.md](official-resources.md) — 年次の公式索引、問題リポジトリ、公式解説、参加記まとめ
- [isucon-problem-solutions.md](isucon-problem-solutions.md) — 各問題の概要、主要なボトルネック、解決策のリスト

## 読み方

解決策は過去問の答えをそのまま現行システムへ適用するための処方箋ではありません。特にキャッシュ、非同期化、データ削減、オンメモリ化は、整合性・再起動・失格条件を満たす必要があります。実戦では、まずベンチマーク、アクセスログ、slow query、プロファイラで現在のボトルネックを確認してください。
